# macOS 原生演示检查

检查对象：`arp-gpui 0.1.2`，GPUI Kit 0.9.0，macOS arm64，Rust 1.95.0 开发构建。基础提交为 `072530fa9a6e5d557ea74e1d90f0d5e1f5854cad`，本次源文件身份见 `source-hashes.json`。最终可执行文件身份见 `native-ui-runtime.json`。

入口为任务自建的 `gpui-ui/target/preview/Power Test GPUI.app` 和 `Power Test GPUI Narrow.app`。仅设置 `ARP_GPUI_DEMO=1`、`ARP_GPUI_DEMO_IDLE=1` 与检查窗口大小。没有启动 Python 后端，没有连接仪器，没有改动演示夹具。临时 app 与可执行文件位于 Git 忽略的 target 目录。

操作与截图通过本会话 CUA 完成。截图保留在本会话工具结果，没有另存为仓库图片。以下记录是人工观察记录，不是自动像素比较结果。

| 场景 | 观察结果 | 范围 |
| --- | --- | --- |
| 1180×760 内容区，2 倍显示比例 | 截图为 2360×1584，包含原生标题栏；三张设备卡在同一行对齐 | 自动与手动页面 |

每次检查结束时通过应用「关闭」或退出快捷键退出任务自建演示进程。CUA 的后续读取返回 `procNotFound`，说明进程不再存在；该返回不是未处理的应用崩溃证据。

未验证：Windows 原生运行和安装器、真实设备和安全下电、扫描等待与重复请求、完整键盘焦点循环、连续拖动缩放、浅色主题、实际 NI-DAQ 采集、原始 Excel/PDF 工作流及性能收益。
