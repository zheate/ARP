# 像素曲线末端小样

用户选择了小蜜蜂、小鱼、吃豆人、激光、小壁虎，并明确要求全部采用可爱的像素风格。

当前交付：index.html 是开发预览；pixel-preview.html 是包含全部脚本的独立离线单文件。pixel-sprites.js 手绘 24 × 24 像素角色，每种四帧动画；Flappy Bird 使用当前工作区原有像素绘制函数作对照。第一轮插画样式保留在 vector-first-round.html，不再作为本轮方案。

小蜜蜂采用蜂蜜黄、像素翅膀和腮红；小鱼采用蓝色圆肚皮、大眼睛和摆尾；吃豆人采用奶黄色阶梯形嘴巴；激光按本轮可爱化要求转成带表情的像素光团；小壁虎采用大头、短身体和交替迈步的小爪子。

全部角色共享同一条模拟曲线，中心跟随数据末端。支持 24 / 32 / 40 px、起伏 / 爬升 / 平稳、浅色 / 深色、暂停 / 继续。右下角放大显示像素细节。系统减少动态效果时默认暂停，页面隐藏时停止累计动画时间。数据和控件状态仅存在内存，不读取设备、不保存测量、不修改正式产品。

本机地址：http://127.0.0.1:8767/ 。需要重启时，在本目录执行 python3 -m http.server 8767 --bind 127.0.0.1 。独立文件也可直接打开。

已查看浅色桌面和窄屏渲染，深色动态帧，实际操作过尺寸、轨迹、主题和暂停按钮。截图检查在 1440、900、390 px 窗口完成，没有控制台错误、横向溢出或加载失败；独立文件另作 1280 px / 2x 像素密度检查。证据分别在 qa-pixel、qa-pixel-motion、qa-standalone。pixel-marker-motion.gif 由本轮真实浏览器帧合成。
