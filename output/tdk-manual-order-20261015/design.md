# TDK 手动控制顺序

卡片按操作顺序排列：连接 TDK → 开启输出 → 设置电流 → 加电 → 归零下电。

只调整手动页面的 TDK 卡片与局部样式。连接和开启移到输入前方，归零下电独占底部一行；保留已有颜色、字体和三张设备卡片的网格。开启前禁用电流输入，加电处理器同时检查连接与输出状态。下电继续绕过普通命令锁，保留失败提示和重试入口。Python 协议与设备指令未修改。

编号说明顺序，橙色（浅色主题跟随现有主色）标出当前可执行的主动作。沿用现有控件的颜色和焦点反馈，没有增加位移、延迟或装饰动画。提示改为“请先开启输出，再设置电流并加电”和“设置电流后点击‘加电’”，移除了与按钮名称不一致的旧指引。
