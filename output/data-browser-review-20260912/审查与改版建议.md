# 数据浏览：审查与改版建议

日期：2026-09-12。范围：自动测试结束、保存历史、选取记录、曲线对比。

用户已明确：自动测试结束后，由操作者选择是否保存到历史记录；需要同时对比不同 SN、不同日期的多条曲线。

结论：主流程应围绕「本次结果 → 手动保存历史 → 多条记录对比」组织。现有页面围绕 Excel 目录浏览组织，单纯调整卡片尺寸不足以满足这次需求。

## 1. 测试结束：缺少手动保存历史的决定点

![当前完成摘要，使用示例完成状态](/Users/zh/Documents/test/ARP/output/data-browser-review-20260912/01-completion.png)

当前组件展示「Excel 已保存」「查看数据」「下一颗」。后端正常完成常规自动测试后会自动排队导出 Excel，缺少独立的历史保存状态。

建议：测试完成后保留本次曲线，显示「未保存到历史」，提供「保存到历史记录」「加入对比」「下一颗」。保存后显示「已保存到历史」，可以直接定位该条记录。备注可选，保存不应要求再次选择文件夹或重填 SN。已保存状态需在重新打开程序后保留，重复点击不能重复建记录。

过程数据继续自动备份，以便故障恢复；自动备份不自动成为正式历史记录。未归档的本次结果进入下一颗时，给出「保存并继续」「不加入历史并继续」「返回」，措辞不暗示原始备份被删除。保存失败时留在未保存状态，保留结果并允许重试。

## 2. 浏览记录：已有查看能力，入口和信息层级需要调整

![当前记录详情，读取已有 QA 工作簿](/Users/zh/Documents/test/ARP/output/data-browser-review-20260912/02-record-detail.png)

已具备 SN/时间/站别/状态筛选、记录详情、测试点表、原文件入口。问题是「选择目录、读取、刷新」占据顶部主要位置，页面缺少主动保存历史的概念。单条详情里的摘要、元数据和选点值占用较多曲线空间。

建议默认进入已保存的历史记录，顶部只保留搜索和常用筛选，将「导入旧 Excel」「打开数据位置」放进次要菜单。旧文件通过明确导入进入历史，保留来源。归档记录保存测试时的 SN、时间、温度、站别、测试点和可用测量数据，避免后续修改样品配置改变历史含义。

## 3. 对比记录：支持跨 SN 的两条记录，多条对比尚未实现

![当前两条对比首屏](/Users/zh/Documents/test/ARP/output/data-browser-review-20260912/03-comparison.png)

本次实测可选 QA-SN-001 和 QA-LEGACY 两个不同 SN。选择两条后，其余有效记录的勾选框禁用。对比模式中，提示、四张摘要卡和两张记录卡把曲线推到视口下方，需要滚动。

还有一处会影响判断：本例把 20 A 下的 226.1 W 与 4 A 下的 24 W 做 ΔPmax，得到 -89.39%。数值计算对应各自最大值，但不能当作相同测试电流下的性能变化。下方共有电流点差值的计算则保留了相同电流匹配的条件。

建议的新页面结构：

| 区域 | 内容和操作 |
| --- | --- |
| 顶部 | 历史记录 / 曲线对比；SN 或备注搜索；时间、站别、温度筛选 |
| 左侧约 300–340 px，可收起 | 紧凑历史记录列表，显示 SN、日期、站别、温度和备注；勾选加入对比 |
| 右侧顶部 | 已选记录清单，每条显示固定颜色、线型、SN、时间；支持设为基准、显示/隐藏、移除 |
| 右侧主体 | 优先显示完整曲线，选择功率、电压、效率或波长等指标；同一图中使用一致的量纲 |
| 右侧底部 | 在选定电流下逐条显示数值、相对基准的差值与百分比；测试点和完整信息放在独立页签 |

对比操作应满足：

- 不再以两条记录作为固定的数据结构，支持多条同时显示；选中清单在筛选、分页、查看详情时保留。
- 颜色和线型绑定记录，移除某条后其他曲线不换色；用图例中的 SN、时间和线型共同区分曲线。
- 没有共同电流点也可以叠加原始曲线。差值按每条记录与基准的共有实测电流点计算，不要求所有记录同时存在该点，不默认插值或外推。
- 某条记录缺失某项指标时说明缺失原因，不填零；不同温度、未完成测试等条件用紧凑提示说明。
- 主要比较选定电流下的功率差；各自 Pmax 保留对应电流，避免直接作为性能优劣结论。
- 自动测试完成后可把「本次结果」直接加入对比；未保存结果持续标明身份，不因为加入对比而自动归档。

## 4. 验收与证据范围

本次仅审查，未修改产品代码。截图来自当前工作区真实 React 组件与样式，在独立浏览器审查容器内运行。列表和详情通过当前 Python 读取代码读取已有 QA 工作簿；完成摘要使用明确标注的示例状态。截图于本次审查捕获，并已查看。

未连接仪器或执行自动测试，未操作正式数据保存，未验证原生 Tauri 的文件对话框、硬件完成流程、系统缩放或完整键盘/读屏行为。审查容器简化了应用外框，不能作为原生界面验收。界面中小字号、紧凑勾选框、低对比图线属于可读性风险，尚未做正式对比度测量。

后续实现的关键验收：保存后重启仍能找到记录；重复保存不新增副本；保存失败可重试；跨 SN 和日期选取至少五条记录；筛选后选择不丢；移除和隐藏曲线不扰动其余记录；基准切换后差值正确；不同电流范围不会形成误导性性能结论；常用桌面尺寸下，完整曲线和主要对比操作同时可见。

建议先据此制作「测试结束保存」和「五条曲线对比」两个状态的页面预览，再落地保存与对比功能。
