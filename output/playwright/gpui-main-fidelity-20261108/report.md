# GPUI 与 main 界面的还原样板

本轮是应用外框和自动测试页的还原样板，不代表六个页面已经完整还原。参考 GitHub `main` 的 `43f11660`。保留当前开发分支的后端、版本 2 协议、测量精度、采集节奏、判稳、持久化和安全下电规则；没有回退到 main 的旧业务实现。

## 为什么差异大

前一次迁移重新组织了内容，未逐项还原既有布局。静态和同尺寸截图对照确认了三个主要问题：

1. 导航改成大面积橙色按钮，缺少原有图标、左侧标记和柔和选中底色。对应 20ui R01/R04/R18。
2. 原有样品铭牌和紧凑设备栏改成大测试计划卡与三张高卡片。首屏曲线位置因此大幅后移。对应 R08/R09/R10。
3. 原来的双曲线、独立关键读数和光谱区改成另一套上下分组，字体、单位基线与图表坐标也未保持一致。对应 R03/R11/R12。

## 本轮方向

- 产品：面向实验室和产线操作员的电源、功率、光谱测试工具。
- 气质：紧凑、精确、克制。
- 环境：沿用 main 的石墨底色、DIN 数字、MiSans 中文及橙色重点色；字体缺失时使用平台字体。
- 重点：完整测量曲线和带单位的读数。
- 细节：同一条设备栏的对齐、真实状态点、阶段轨迹与稳定的底部操作位置。

本轮使用 unslop（Damir Sokolovsky，https://heydamir.design/unslop，CC BY 4.0）和 20ui 的检查方法。既有 main 是还原方向，没有引入新的视觉风格。其他页面的批量还原仍等待样板确认。

## 实现边界

`workbench.rs` 集中保存样板结构。主页面恢复样品信息、脚本、输出目录、设备栏、开始/停止、两张曲线、四张关键读数和光谱区。原有恢复操作与 SMSR 保留在下方运行详情中。设备设置继续使用既有共享弹窗；连接与采集操作在对应弹窗内保持可达。

应用外框与公共配色同步采用 main 的中性色和橙色。文件夹按钮保留中文悬停标签和可访问名称。图标继续使用现有 GPUI Kit 中的 Lucide 资源，仅嵌入实际使用的图标。

原生图表补齐坐标、功率/效率双轴和图例。绘图平滑移植既有 `monotone-curve.ts` 的单调插值，仅改变像素曲线。原始 binary64 样本与导出数据不变。电流计划范围只作显示提示，自定义电流超出计划时仍扩大坐标范围显示全部已测点。

启动时赋予页面焦点，使退出快捷键在没有先操作输入框的情况下也有页面上下文。关闭弹窗仍返回持久页面焦点，复用既有安全退出处理。

## 证据与结果

- `main-1180x760.png`、`main-960x640.png`：从 `main` 提取的独立参考源码，用独立 Playwright Chromium 与临时资料目录采集。浏览器会话和任务自建 Vite 服务均关闭。预览复用当前已安装的前端依赖，Vite 为 7.3.6；这不是冻结 main 锁文件后的像素基准。
- macOS GPUI 截图在本会话 CUA 结果中。1180×760 和 960×640 为内容区，原生截图另包含系统标题栏。没有把 CUA 图像伪装成本地 PNG，也没有执行自动像素差比较。
- 1180×760 演示：双曲线和关键读数同时可见；单位完整显示；PIB 为 `96.85 %`；FWHM 按现有 `0.6 nm` 规格显示超限色；导航内容左对齐。
- 960×640 演示：设备栏保持对齐；开始/停止使用固定的紧凑操作组；输出目录图标按钮的可访问名称为「选择输出目录」。宽、窄检查分别使用已有运行/空闲夹具，没有改写夹具。
- 三个设备弹窗：资源列表均可展开并选择；选择后弹窗保留；电源列表的第一次 Escape 收起列表，第二次关闭弹窗。电源连接/断开、功率计与光谱仪开始采集入口在对应弹窗中可见。
- 功率计「识别」演示：仅提示未发送设备命令；页脚标签与布局保持。弹窗期间点击背景系统设置，关闭后仍在自动测试页。真实扫描的 pending 状态没有验证。
- 退出快捷键可退出演示。CUA 随后的 `App quit`/`procNotFound` 表示演示进程已退出。最后关闭窄窗口并保留主样板用于查看。
- `npm run build`：macOS arm64 开发构建通过，见 `build.txt`。
- `npm run test:gpui`：17 项通过，见 `core-tests.txt`。
- `cargo test --manifest-path gpui-ui/Cargo.toml --locked --bin arp-gpui`：3 项绘图检查通过，见 `drawing-tests.txt`。覆盖非均匀采样窄峰的曲线范围、负值/无效样本坐标、计划范围不得隐藏自定义测量点。窄峰检查用填充细分验证曲线中心线，排除描边斜接扩展。
- `cargo fmt --check` 和 `git diff --check`：通过。

本轮没有修改 Python 设备、计算、数据存储模块，没有连接或控制真实设备。版本和源文件/可执行文件 SHA-256 见 `provenance.json`。

## 仍有差异

这不是逐像素还原。原生系统标题栏仍保留。显示菜单、脚本添加入口、历史参考曲线、峰值标注和完整显示偏好尚未按 main 逐项还原。手动配置、PD、数据浏览、出货报告和系统设置的内容布局也尚未按此样板批量还原；公共配色与曲线绘制已共用。

Windows 原生运行、实际设备、真实扫描等待、完整键盘遍历、Excel/PDF 全流程和性能收益未验证。只完成本轮演示与聚焦测试，不据此宣称完整迁移或生产验收完成。
