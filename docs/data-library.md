# 测试数据库与数据对比

原生虚拟演示：在项目根目录运行 `npm --prefix tauri-ui run demo:data`。直接打开 Tauri 数据浏览页，填充 55 条内存中的虚拟记录并预选 5 条电光效率曲线；可切换全部参数、筛选和查看光谱。页面常驻演示提示，后端请求被隔离，关闭窗口也不保存配置。正常 `npm start` 不加载虚拟记录。

数据浏览默认打开本地测试数据库。完整结束的自动测试，以及明确保存的手动测试，自动存档；中止、未完成和无有效功率点的记录不进入此库。流程完成不表示产品质量合格。Excel 原有生成流程继续保留，即使 Excel 导出失败，已完成测试也可从数据库查看。

数据库位于应用 settings.json 同级的 `test-records/library.sqlite3`。存档包含会话配置、设备信息、测试点、光谱和原始日志。采用 SQLite 事务和 WAL；数据库同步失败不会干扰安全下电，JSONL 日志继续保留，打开数据浏览时重试同步。恢复扫描兼容旧的 `station-*` 日志目录。此数据库保存在本机。

旧 Excel 使用“Excel 文件 → 选择目录 → 导入已完成测试”。导入会备份整个工作簿，同时建立可查询的数据记录，不改写原文件。具有会话编号的文件按会话去重，其他文件按完整内容去重。旧格式未标记完成状态的文件仍可只读浏览，但不会自动判作成功存档。文件后来移动或删除，不影响已入库数据和光谱的查看；“打开 Excel”仍定位原始文件。

左侧记录列表宽度为 270–320 px，正文为 14–16 px。可跨 SN、跨日期选择 2–5 条记录，筛选和翻页保留选择。曲线与差值表支持功率、电压、电光效率、峰值波长、质心波长、FWHM、PIB、SMSR。功率保留零点参照，其他参数按实测范围设置纵轴。差值只匹配相同实测电流（归一到 6 位小数），不插值；重复电流或缺失参数不计算差值，效率和 PIB 的差值为百分点。完整光谱按需读取。

验证：19 项 Python 定向测试、12 项前端数据测试、Rust 请求超时定向测试及前端构建通过。浏览器使用 55 条隔离测试会话和真实 Python 文件接口，检查了 5 曲线、8 参数、基准切换、筛选与翻页、详情放大、Excel 导入及光谱读取；在 1280×800、1440×1000、1920×1080 检查了布局。截图保存在 `output/playwright/data-library-20260917/`。未连接真实仪器，未打包或发布，浏览器验证不替代 Tauri 原生运行与真实设备验收。
