# ARP UI/UX 与前端审查 — 2026-09-14

基线：`main` 的 `452847718cacb36e028928bfae1b77e9e55e4107`。依据 `DESIGN.md` 和原有 `design-qa.md`，保留石墨色仪器工作台、ARP Orange 操作色、DIN 数字及现有业务流程；没有建立另一套视觉语言。

## 结论与覆盖

主要差距是数据语义、真正的模态交互、小窗口中的测量空间，以及基础控件一致性，而不是品牌或装饰不足。审查覆盖自动测试、手动配置、PD、出货报告、数据浏览和系统设置，以及设备设置、规格、系数方案、脚本保存、保护、暂停、结束/导出失败和下电未确认弹窗。

原 design-qa 是四张测量卡的对齐专项记录，其 passed 不等于整机界面和异常状态通过。本次保留其历史，增加可执行的回归流程。数据浏览/报告的空状态和布局已检查，真实记录与真实文件生成尚未验证；不为填满这些页面增加卡片。

## P0：数据理解与操作风险

| 问题 | 实际修改 | 原因与边界 |
|---|---|---|
| 手动页实时功率旁可能显示设定电流 | TDK 使用 outputCurrentA；CH341 保留 activeCurrentA 来源；断开/缺失显示 --，不再回退到 setCurrentA | 计划输出不能冒充回读；未修改驱动。CH341 指令状态也不是新增的独立电流测量 |
| 保护弹窗无条件写已断电，结束弹窗无条件写 JSONL 已保存 | 保护提示要求核对下电结果和实体面板；记录说明仅反映是否提供路径；保留测试点、日志和实际导出/下电状态 | 通知或文件路径不能独自证明物理安全或成功持久化；没有改变下电、退出、保存命令 |

## P1：效率、层级和一致性

| 问题 | 实际修改 | 可观察的收益 |
|---|---|---|
| 弹窗打开后 Tab 可进入背景 | 共用 DialogPortal：焦点循环、背景 inert、恢复焦点、拦截背景页面快捷键；保留各弹窗 Escape/保存/确认规则 | 基线 9 次设备弹窗焦点逃逸得到修复；保存中、长异常文本和安全确认独立回归 |
| 1366×768 上方参数过高，谱图掉出首屏 | 样品栏推迟折行，标题栏接近 50 px；按可用高度压缩次要栏，保留读数与谱图 | 光谱 canvas 从底部约 1006 px 移至 741 px；1920×1080 光谱 canvas 为 322 px 高 |
| PD 操作在长表单底部，运行中参数可变 | 操作和状态移至滚动参数区外；字段组在运行中禁用，停止按钮不在禁用组内 | 1366×768 开始按钮由约 y=827 移至 y=175；运行状态验证停止仍可用 |
| PD 新 fieldset 使容器查询失效 | 在原容器规则中覆盖 fieldset 的子项跨度，并增加字段宽度/重叠断言 | 修复截图暴露的隐式第二列和文字挤压，而不是以构建成功结案 |
| Field/Input/Select 的关联和下拉行为不一致 | 提取共用 Field、NativeSelect；支持现有 ariaLabel 与标准 aria-label；菜单按视口及裁剪祖先选择方向和高度 | 保留本地 popup，不改 portal；长名称可读，展开不移动表单/页脚 |
| 数字与单位移动；常态测量颜色与告警混淆 | 保留数值字符宽度；普通有效值使用中性色；规格结果增加图标和文字，缺失/过期/无效分开呈现 | 9.999→10.000、999.999→1000.000、负数及 -- 的实际 React 更新验证几何稳定 |

## P2：细节完善

统一本轮涉及的 28/32/36 px 控件高度、4/6/8 px 圆角、弹窗边界与双主题键盘焦点。去掉启动按钮发光和阶段循环流光；数字变化提示缩短、移除 glow 并尊重 reduced-motion。保留有操作含义的检测、加载和状态反馈。报告的单个/批量切换增加明确选择语义。
