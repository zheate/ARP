## P0：操作 / 安全相关的 UI 边界

**模态焦点隔离不足。** 基线在三类设备弹窗、三种窗口条件中复现 9 次 Tab 逃逸。新增共享 `DialogPortal`：背景 inert、Tab / Shift+Tab 约束、关闭后恢复触发控件焦点，以及模态期间页面切换快捷键守卫。保留原有 Escape、保存锁和安全确认策略。这里的 P0 是背景误操作风险，不是声称确认了硬件故障。

**长告警挤压关键操作。** 状态弹窗限制在视口内，正文可滚动，头部和操作区不收缩。以实际保护、暂停和下电失败组件，在 1920×1080、1366×768、960×540 / DPR 2 验证 70 行长文本。确认/重试区可见、焦点受限；没有人工确认下电时，强制退出保持禁用。未修改后端下电判据、确认条件或动作回调。

## P1：效率、信息层级与一致性

**自动测试首屏空间。** 1366×768 下 metadata 过早换行、标题栏/设备条偏高，光谱大部在视口外。先压缩次要区域，保持主读数、设备状态和操作。光谱绘图区从约 `y=724..1006` 变为 `y=535..741`，最终绘图高度约 206 CSS px；1920×1080 为 322 CSS px，2560×1440 约 474 CSS px。极小逻辑窗口仍需纵向滚动，次要历史曲线后移。

**PD 操作可达性。** 原 1366×768 开始/停止按钮位于 `y=827..859`；现在位于 `y=175..207`。参数区独立滚动，运行时由原生 fieldset 禁用参数，但停止按钮置于其外，保持可用。命令及参数未变。截图发现新增 fieldset 导致旧容器查询跨列选择器漏匹配，已修复，并补充字段宽度/标签边界/重叠检查。

**数据质量与限值的解释。** 原代码已过滤 stale 数据，不应将其误述为“所有旧数据均会被判为通过”。本次补足有效性文字/图标及非有限值语义：达标、超限、无实时数据、数据过期、数据无效。正常功率不再永久使用 warning 色；正常数值保持高对比中性色，超限仍突出。阈值比较、PIB 换算、显示精度不变。

**公共表单/下拉。** Field 将标签关联到实际 Input、NumberInput、NativeSelect；兼容 ariaLabel 和 aria-label。下拉保留在弹窗内，根据视口和所有裁剪祖先的可用空间上翻/限高，不改变保存区几何。报告模式使用 aria-pressed，不引入未实现键盘契约的假 Tabs。

## P2：稳定几何与视觉细节

不仅使用等宽数字，还为完整数值区域和电流区域保留宽度。实际 React 更新验证 `9.999 → 10.000 → 999.999 → 1000.000`、负值和 `--`，数值与单位位置稳定；不是对任意长度数据的承诺。

共享 28 / 32 / 36 px 控件高度和 4 / 6 / 8 px 常用圆角 token；浅/深色使用可见键盘焦点。移除按钮装饰 glow 和循环跑光，保留有意义的短暂数值变化提示，并尊重 reduced motion。不为各页面创建重复视觉版本。
