# 数据浏览页面第一版实施计划

日期：2026-09-10  
状态：计划已整理，尚未开始功能实现。

## 目标与范围

完成“选择数据目录 → 查找一次测试 → 查看功率曲线与测试点 → 对比两次测试 → 打开原文件”的完整流程。面向日常查数、同一 SN 复测及封盖前后复核，沿用应用现有主题、橙色强调色和图表组件。

第一版包含：

- 递归读取用户选择目录中的测试 Excel（`.xlsx`）。
- SN、日期、测试站别、记录状态筛选；默认按时间倒序。
- 一次测试一条记录，显示同一 SN 的多次测试，不覆盖、不自动合并。
- 记录详情、功率—电流曲线、测试点表格和已有测试元数据。
- 两次测试的功率曲线叠加，以及共有电流点的功率差值。
- 打开 Excel、打开所在文件夹；保留筛选、选择和滚动位置。

后续扩展：按 SN 折叠分组、3～4 次测试比较、效率与光谱联动、测量尝试时间线、汇总导出和出货报告页面联动。仅存在 JSONL、尚未导出 Excel 的会话检索也放在后续阶段。

## 页面与交互

### 1. 顶部筛选栏

- 数据目录：首次默认使用当前测试输出目录，可单独选择并记住浏览目录，不修改自动测试的输出设置。
- SN：输入后短暂防抖检索，支持部分匹配。
- 日期：全部、今天、最近 7 天、自定义；首次使用默认全部。
- 测试站别与记录状态：从当前目录的索引中生成选项，提供“全部”。
- 刷新与结果数量：进入页面及手动刷新时更新目录索引；筛选变化优先查询已有索引。
- “工位 1/2”仅在导出数据确实包含该字段时启用筛选，不能从当前所选工位或测试站别推断。

### 2. 左侧列表与右侧详情

- 宽屏使用约 35% / 65% 的列表、详情比例，分别滚动。
- 列表使用紧凑表格，主要列为 SN、测试时间、测试站别和状态；提供比较用复选框。
- 默认每页 50 条，显示总数；左侧宽度不足时把站别与状态放到第二行，保持 SN 和时间可读。
- 默认选择排序后的首条可读取记录；筛选后若原选中项仍存在则保留，否则选择新结果首条。没有结果时清空详情并显示空状态。
- 详情顶部显示 SN、测试时间、站别、温度、测试模式和完成情况；数据缺失显示“未记录”。
- 详情提供“曲线概览 / 测试点 / 测试信息”三个页签；支持展开详情，并能返回原列表位置。
- 1366×768 下使用更紧凑的列表及可展开详情，避免靠挤压曲线与表格字号适配。

### 3. 单次测试查看

- 默认展示功率—电流曲线，坐标单位明确为 A 和 W。
- 关键指标显示所选电流点对应的功率，不把最大功率与其他电流点的指标拼成一组。
- 第一版用电流点选择器与表格行选择联动指标和图表选中标记，不依赖悬停才能读取结果。
- 测试点表保留文件中已有的电流、电压、功率、效率及光谱指标列；缺失值为空值，不补零、不重新生成缺失光谱。
- 区分峰值波长与中心波长；效率和 PIB 的百分数换算复用现有解析规则。
- 测试信息展示可读的元数据及完整文件路径；隐藏工作表正常读取，但不改变原文件的可见性设置。

### 4. 两次测试对比

- 勾选两条有有效电流/功率数据的记录后启用“对比”；第一版最多选择两条。
- 默认第一条作为基准，可交换基准；图例固定包含 SN、站别和时间，颜色与数据表一致。
- 两条曲线保留各自全部有效点；差值表仅对齐两份文件共有的有效电流点。
- 电流匹配采用明确的小数精度归一规则，建议六位小数；不做最近邻配对或隐式插值。归一后重复的电流点标记为无法唯一匹配，不默默平均或覆盖。
- 绝对差值为“对比记录功率 − 基准功率”，百分比为“差值 / 基准功率 × 100%”。基准功率为零时百分比显示 `--`，仍显示绝对差值。
- 没有共有电流点时仍展示曲线，同时解释为何没有差值结果。
- 两条记录的温度、站别、时间和完成情况持续可见；中断记录可比较已有点，但标明数据不完整。
- 比较选择独立于当前列表筛选显示为已选条目，可逐个移除；切换数据目录时清空比较选择。

## 数据规则

- 以规范化源文件路径作为当前目录中的记录标识；同 SN、同时间但不同文件保留为不同记录。若有会话编号，作为元数据保留，不据此自动删除副本。
- 显式完成、操作员停止、安全中止、下电未确认等状态根据会话字段呈现；旧文件缺少状态时显示“完成情况未知”。不以“能读到测试点”代替完成判定，也不显示无判定依据的合格/不合格。
- 读取状态与流程状态分开：一个文件可以“可读取但已中止”，也可以“读取失败，流程状态未知”。
- 时间优先取会话开始时间，转换为本地时间；缺失时使用文件修改时间，并在列表及详情标明时间来源。自定义日期使用本地自然日边界。
- SN 优先取明确元数据；若从已识别的标准目录结构提取，标明“由目录推定”。无法可靠提取时显示“未记录”，不使用当前测试输入框的 SN。
- 测试温度保留导出的原始文本，允许“水冷25°C”等值，不强制转换为数值。
- 临时锁文件 `~$*.xlsx` 跳过；损坏、权限不足、格式不支持等文件记录可见的文件级错误，不能使整个目录加载失败。
- 刷新发现源文件已删除或移动时更新列表及当前详情状态；不继续把缓存内容标为最新数据。
- 原始 Excel 只读。第一版只解释已有数据，不追补设备读数或修改导出结果。

## 实施步骤

### 步骤一：记录读取与数据契约

新增独立的 `combined_test/data_browser.py`，复用已有表头及会话字段语义，提供轻量摘要与按需详情读取。保持自动测试现有历史参考筛选规则。

定义前后端一致的摘要、详情、流程状态、读取状态、缺失字段、时间来源和错误结构。详情中的测试点保留原行标识和可选数值字段；列表阶段不读取光谱数组和测量尝试明细。

验收：现代格式、旧格式、手动单点、中断和损坏文件均有明确结果，元数据和测试点可追溯到源文件。

### 步骤二：目录索引与桥接接口

第一版使用进程内目录索引和有上限的文件解析缓存，不引入数据库。缓存键包含规范化路径、修改时间和文件大小；刷新时更新新增、变更与删除的文件。Windows 路径大小写及子目录遍历需保持一致，避免循环访问链接目录。

拟新增两个后台文件请求：

| 请求 | 参数重点 | 返回内容 |
| --- | --- | --- |
| `dataBrowser.list` | `rootPath`、`refresh`、SN/日期/站别/状态筛选、页码及每页数量 | 当前页摘要、总数、筛选选项、索引时间、文件级错误数量 |
| `dataBrowser.inspect` | `path`、已知文件版本 | 当前文件元数据、测试点、读取警告与新版本标识 |

目录读取使用现有后台文件任务路由；长任务期间显示加载状态，防止重复刷新；快速切换目录或记录时，以请求序号丢弃过期响应。文件列表和历史测试点不进入高频设备快照。

验收：单个文件失败不阻断其他记录；未变化文件复用解析缓存；长扫描期间快照及硬件控制队列仍可响应。

### 步骤三：页面骨架与查询流程

新增独立的 `tauri-ui/src/components/data-browser-page.tsx` 及 `tauri-ui/src/lib/data-browser.ts`，在 `App.tsx` 中只接入导航、页面和必要状态。

补齐 Page、快照视图、滚动位置和导航快捷键相关类型；为 `data` 明确提供只含必要状态的快照路径，避免进入该页后订阅完整实时图表数据。页面切换沿用现有自动测试交互锁及告警处理规则。

完成目录选择、加载/空/失败状态、筛选、分页、选中项、三个详情页签、展开/返回和页面状态保持。使用现有主题变量、按钮、表格与焦点样式。

验收：用户从选择目录到打开一条记录的流程完整；快速切换不会串用其他记录内容；长 SN、长路径与小窗口仍能操作。

### 步骤四：曲线、测试点及两次比较

复用 `CanvasLineChart` 绘制单次与双记录功率曲线；将匹配电流、计算差值及显示格式放入可独立验证的纯函数。

验收：图表与表格来自同一数据源；缺失、重复电流点和基准功率为零均按前述规则处理；温度、站别和数据完整性随对比持续展示。

### 步骤五：文件操作与异常恢复

复用 `openResultFile` 打开原文件、回退定位及展示错误；“打开所在文件夹”直接定位选中文件。记录详情加载后文件再次变化、被移动或被占用时，提示刷新或重试，不显示无依据的成功提示。

验收：打开及定位均等待真实结果；失败原因可见；刷新后恢复可读取文件，无需重启应用。

### 步骤六：回归与桌面验收

- 后端：用临时目录和生成的小型测试工作簿覆盖现代/旧格式、隐藏元数据、手动单点、中断、损坏、重复记录、缓存失效、删除、日期边界及后台任务路由；Python 测试从仓库根目录运行。
- 前端：覆盖电流对齐、功率差值、零基准、缺失值、重复电流和过期请求结果；运行现有前端测试及生产构建。
- 回归：验证原有同 SN 自动测试参考记录筛选、出货报告完成状态校验、快照视图与文件打开逻辑。
- 桌面：在真实 Tauri 窗口检查 1366×768 与 1920×1080，覆盖现有深浅主题、筛选、滚动、展开返回、双记录对比及文件操作；硬件相关并发检查使用模拟设备。
- 性能：以约 1000 个小型测试文件验证列表分页与缓存，以少量含大光谱数据的文件验证列表路径不加载光谱；记录首次扫描和二次刷新的耗时、界面响应与缓存上限，不预先承诺固定秒数。

验收场景：选择包含同一 SN 的封盖前、封盖后及中断记录的目录，筛选该 SN，打开两条有效记录并查看共有电流下的功率变化，随后打开各自的原始 Excel；整个过程中原始文件内容不改变。

## 交付与顺序

实施按“读取契约 → 后台接口 → 页面查询 → 曲线对比 → 文件操作 → 桌面验收”顺序推进。第一版完成后再评估光谱查看、更多记录对比和出货报告联动。

本次交付仅为计划文档；功能代码、测试数据及构建产物尚未创建。
