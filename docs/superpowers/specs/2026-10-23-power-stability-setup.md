# 功率判稳参数：自动学习与容差预设

本次按用户授权简化参数配置，替代第一版要求手填步进及全部高级参数的入口。默认仍为旁路验证，不自动切换为双窗口控制；不增加硬件查询、扫描或主动加电流程。

## 日常操作

1. 选择测试容差预设并保存。内置「标准」使用相对漂移 0.2%、绝对漂移 0 W、参考时间 20 s、额外 2σ 波动 0%。这些数值用于双窗口算法；原有控制策略及其按电流、驱动选择的规则不变。标准预设不会根据噪声自动放宽。
2. 从现有采集流自动取得可用设备信息；未提供的量程或滤波如实显示未知。0 A、无光、探头已冷却仍由操作者确认，然后启动 180 秒本底学习。零点、噪声和漂移保护量及观测步进由软件计算、保存和复用。手动步进保留为维护覆盖项，默认 0。
3. 响应时间、电流建立时间、回读容差放入「设备响应」折叠区域，按设备规格或实测确认一次并保存。本底数据无法推导这三项，本版不增加带电响应测量。

旧配置中已有的漂移或额外波动容差迁移为「已保存的自定义容差」。切换到标准预设不覆盖自定义值，切回即可复用。设备响应确认单独绑定探头、系数、设置、采样间隔及电源，切换容差预设不使其失效。旧确认签名仅在身份和原参数匹配时接受，保存时升级；普通保存不能为已失效的确认重新签名。

## 自动学习的边界

观测步进通过原有网格、重复台阶、连续性和冷却趋势检查后，可以直接参与双窗口判稳，无需把数值重新抄入手动步进。它仍不是仪器原生分辨率；估计失败不产生可用本底。仪器设置备注真正可选，不再以填非空文字作为控制门槛；修改未能读取的面板设置后仍需重新学习。

双窗口控制仍要求有效容差、已确认的设备响应、匹配且复核有效的本底及连续新鲜采样。本底保护量超过预设容差时报告测量能力不足，不自动扩大容差，也不静默回退原有策略。5 s / 20 s 计算、稳定保持、电压读取期间复核、完整原始数据、中位数记录、安全下电与硬件命令间隔不变。

## 离线验证范围

针对性测试覆盖学习值直接控制、空备注、预设切换、自定义值保留、旧配置与签名迁移、重启复用、身份变化后的显式重确认及能力不足拒绝。生产弹窗组件的隔离预览覆盖 1440×900、1180×900、760×600 的三类设备下拉框、Escape、识别期间页脚稳定、响应确认保存复用、自动学习展示和布局边界。预览使用示例数据，不访问设备。

源码及离线验证不证明真实探头噪声、响应时间、仪器设置可读性或 Windows Tauri/WebView 行为；本次交付为源码，未连接设备或制作安装包。
