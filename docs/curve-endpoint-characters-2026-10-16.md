# 功率曲线末端：小蜜蜂与小恐龙

已将用户确认的两种动画加入正式 Tauri 前端。入口为“系统设置 → 外观 → 曲线尾迹 → 末端样式”。新增“小蜜蜂”和“小恐龙”，选择后即时预览，沿用现有本地存储键保存和恢复；未知值仍回退为圆点。其余样式保留。

小蜜蜂采用四帧、10 fps；小恐龙采用四帧、8 fps。正式界面默认显示为 32 CSS px。原始透明 PNG 保存在 `tauri-ui/public/chart-markers/`，文件名带内容摘要，构建会原样复制到发布目录。两张原图约 1.37 MB。显示区域沿用本聊天已确认的裁切与眼部对齐参数，不重新绘制图案。

角色在加载时合成为一条四帧 Canvas 精灵条，并按样式、尺寸和像素密度缓存。运行时由 CSS 步进动画播放，不为每个动作帧触发 React 更新或重绘测量曲线。角色中心与曲线使用同一绘制快照，复用既有小鸟的连续揭示和坐标轴过渡。增加相应的顶部、右侧留白；功率及电流读数保持在装饰角色上层。没有改动采集、计算、完整数据、稳定规则或设备命令。

系统减少动态效果时显示静止帧；页面或角色不可见、数据为空时停止播放。图片失败时在相同数据位置显示圆点。加载完成和卸载均有生命周期保护；视图切换不保留多余的观察器和事件监听。
