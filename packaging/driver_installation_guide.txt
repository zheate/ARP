Power Test 安装与修复说明

正常安装只需运行发布者提供的一个完整安装包：
Power Test_<版本号>_x64-all-drivers-setup.exe

1. 允许 Windows 管理员权限提示。
2. 保持默认组件可安装全部设备支持；也可取消不使用的设备。
3. 点击安装，等待 WebView2、所选驱动和 Power Test 安装完成。
4. 按完成页提示处理重启。若提示“安装尚未完成”，请重启后使用本次安装的同一管理员账户登录，安装会继续。
5. 启动 Power Test，导入对应电脑的许可证，再连接设备并执行识别。

组件如何选择

- Power Test + WebView2：必需。已经检测到的机器级 WebView2 会跳过安装。
- CH341 I²C：旧式泵驱电源控制器。
- Ocean Insight / OceanHR4：光谱仪。具体型号须使用与该设备匹配的厂商驱动。
- LaserPoint / FTDI：LaserPoint 的 USB 转串口驱动；同时保留 NI-VISA。
- CH341 / CH343：使用这两类 USB 转串口芯片的设备。
- NI-VISA：Caihuang、LaserPoint、Coherent 或 TDK 等串口仪器使用的运行环境。
- NI-DAQmx：PD 数据采集卡。
- Ophir：安装 StarLab 及其 USB/COM 组件。
- Coherent：安装 Meter Connection 及 PowerMax USB 驱动；串口连接同时保留 NI-VISA。

错误与重试

安装失败时不会显示全部完成。请先查看：
C:\ProgramData\Power Test\InstallerLogs

完整流程日志 full-setup-*.log 包含失败组件和退出码。
应用 MSI 日志为 application-msi.log；Coherent 厂商日志为 coherent.log。
驱动的系统日志为 C:\Windows\INF\setupapi.dev.log。
若显示超时，厂商安装程序可能仍在运行。再次安装会检查该进程是否结束，并拦截重复执行。
等待其结束或重启 Windows，修复日志所指问题后，再运行同一个完整安装包。
驱动文件缺失、校验不符或签名不受信任时，请向发布者获取完整、可信的安装包。
不要关闭 Windows 驱动签名检查。

自动继续安装使用一次性计划任务“Power Test Setup Resume”。
任务仅在需要中途重启时创建，并在读取续装状态前删除；即使状态文件损坏，也不会每次登录都重复执行。
如继续安装失败，查看日志并重新运行完整安装包即可。
安装缓存位于 C:\Program Files\Common Files\ARP\Setup\<版本号>\<本次安装>。
自动继续前不要移动或删除该目录；仅保存缓存不代表已经安装驱动。

安装前会检测本产品的运行进程；若仍在运行，请从软件正常结束测试并退出。安装程序不会强制关闭它。
安装程序不会主动控制仪器或开启电源输出。
安装成功不等于真实设备验收；应验证识别、采集、Excel 导出及安全下电。
