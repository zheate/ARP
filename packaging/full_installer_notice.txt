Power Test 应用与离线驱动文件包

本安装包只安装 Power Test，不会自动安装任何硬件驱动或厂商软件。

Power Test 所需的 Microsoft WebView2 离线运行库已包含在主程序 MSI 中；缺少时会自动安装，不会联网下载。WebView2 是应用运行环境，不是硬件驱动。

下列离线驱动文件会复制到 C:\ProgramData\Power Test\Drivers，供用户按需手动安装：

- WCH CH341 I2C 和 CH341/CH343 串口驱动
- Ocean Optics OceanHR4 WinUSB 驱动
- LaserPoint / FTDI USB 串口驱动
- Ophir StarLab、Ophir USB 驱动及 COM 接口
- Coherent Meter Connection / PowerMax USB 驱动
- National Instruments Package Manager 24.0
- NI-DAQmx Runtime 23.5
- NI-VISA Runtime 23.5

安装结束后请打开该目录，阅读 DRIVER-INSTALLATION.txt，只安装实际使用设备对应的驱动。
手动安装厂商驱动表示您接受对应厂商的许可条款。部分驱动安装后可能需要重启电脑。

Power Test 安装过程不会执行驱动安装程序，也不会从互联网下载驱动。
